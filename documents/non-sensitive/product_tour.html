Red Team Active & Passive Reconnaissance Modules

CyFence identifies perimeter defenses, discovery mechanisms, and dangerous server routes before attackers exploit them:

🧱

WAF & CDN Fingerprinting

Analyzes response header patterns and security cookies to identify perimeter proxies:

  • ✓ Cloudflare (cf-ray, __cf_bm)
  • ✓ AWS CloudFront & WAF (x-amz-cf-id)
  • ✓ Akamai Edge (akamai-origin-hop)
  • ✓ Imperva / Incapsula (X-Iinfo)
📁

Sensitive Route Probing

Probes for accidental source code and secret exposures without invasive fuzzing:

  • 🚨 /.git/HEAD (Repository metadata)
  • 🚨 /.env (Database credentials)
  • ⚠️ /actuator/env (Spring Boot vars)
  • ℹ️ /swagger.json (API specs)
🧭

Discovery & security.txt

Verifies responsible disclosure infrastructure and discovery protocols:

  • ✓ RFC 9116 /.well-known/security.txt
  • ✓ Contact & Canonical URLs
  • ✓ Robots.txt sensitive path disallow
  • ✓ Cross-Domain clientaccesspolicy.xml
🎯
Framework Alignment: Every finding maps directly to MITRE ATT&CK (e.g. T1592.002, T1595, T1552) and MITRE D3FEND countermeasures.
